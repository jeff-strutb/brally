# Idioms from lane f91b2095 (2026-08-31)

## Named double temps bloat a 65 B cross product to 91 B

`double x = a.y*b.z - ...; pOut->x = x;` copies through integer slots.
Orig fstp's each component as it is computed. Distinguisher: +26 B,
extra movs. Direct `pOut->x = ...` size-matches 65 B; remaining gap is
arg register edx/ecx/eax vs ecx/eax/edx and x87 operand order.

## Nav f00(1) is `push 1; call [eax]`, not __fastcall edx=1

Orig `mov eax,[ecx]; push 1; call [eax]`. C `__fastcall(this, 1)` emits
`mov edx,1; call [eax]`. 4-byte struct arg added a byte. Distinguisher:
`6a 01 ff 10` vs `ba 01 00 00 00 ff 10`.

## DpCreateIface success is `jge` to a later block, fail is fall-through

After QI, orig `test esi; jge success` with fail immediately below.
`if (hr >= 0) { success; return; } fail:` compiles `jl fail` with
success first. Distinguisher: `7d xx` vs `7c xx` at the same test.

## EntGfxFreeAll CSEs free into ebx, REGNORM 0

`mov ebx, [IAT free]; ... call ebx`. Size 153/153. Residue is push-edi
placement and `[eax+esi]` vs `[esi+eax]` SIB. Not tagged.
