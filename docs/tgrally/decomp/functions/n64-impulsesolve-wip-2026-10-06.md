- J cross product right products reversed: `nb[1]*J[2] - nb[2]*J[1]` etc.

Mechanism (proven): ugen generates each procedure TWICE; pass 2 (the emitted one) starts with the FP temp free list left by pass 1, so FP temp names in the whole function are a permutation sigma = pass-1 last-use order (oldest first) of f4/f6/f8/f10/f18. The FP free list is a strict FIFO (get = head, free = append). One extra get anywhere rotates every later name. Residue = ROM spends ONE more FP temp between the tn[2] load of the third difference and the join's tn[0] load (in both passes); injecting one rotation there (DKWB_INJECT_FP) gives EXACT. as1 then also hoists the join's tn[0] load above the beqz, as the ROM does.
