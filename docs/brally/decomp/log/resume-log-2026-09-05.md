## SEVEN STANDING WARNINGS
1. Never repeat "image gate 0 diff bytes" without re-running it; the gate compiles its own objects and has three outcomes (FAILED / INCONCLUSIVE / exit 2); a header edit silently un-matches every TU nobody re-sweeps.
2. Before ANY target: `ls src/core/cpp/<VA>.cpp` and grep report_cpp.csv - finished C++ rows and d3d-tagged functions read as untouched.
3. "The lane ledger is exhausted" is NOT "no work" - triage sees only TAGGED diffing functions; T1 is the work.
4. Re-measure a note's claim - "unreachable"/"parity" notes have been overturned repeatedly. Leads, not verdicts.
5. Low reggap means WELL-WORKED, not easy.
6. A region count can cover only PART of a function - read divergence.py's `NEVER COMPARED` line ([lost-sync-region-trap](../traps/lost-sync-region-trap.md)); `msetdiff.py --orig-range/--recomp-range` is the only way inside a lost-sync gap.
