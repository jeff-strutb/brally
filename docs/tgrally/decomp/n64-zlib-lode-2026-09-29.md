# N64 zlib lode

*Recorded 2026-09-29.*

> TGR N64 ROM carries zlib 1.0.4 inflate (0x8023EDB0-0x80242940); all 28 functions byte-exact from zlib's own source in src/tgrally/gamedata/zlib/

2026-09-29 (session d56b1a6a): the ROM's inflate is zlib 1.0.4 (version + " inflate 1.0.4 Copyright 1995-1996 Mark Adler " strings in the image). zlib's original source compiled under IDO -O2 is BYTE-EXACT: 28 functions, commits 5bd6ac9f..a460bfbb, files src/tgrally/gamedata/zlib/{infblock,inflate,inftrees,infcodes,inffast,infutil,adler32,zutil,uncompr}.c + src/tgrally/include/tgr/zinfl.h (the zlib notice kept; altered files marked).

Game changes to find by diff, not guess: inflateInit2_ with no zalloc sets up a bump heap (BrZHeap at 0x80368AC8 over the unpack scratch range, else over the frame buffers with osViBlack(1) + D_8028A888=2); zcalloc = bump alloc, hangs on overflow; zcfree empty; inflate_fast hangs when a distance link == 0x10001. uncompress keeps the ROM name BrInflate.

**Why:** the fastest T4 intake of the session (~15K bytes of code in a few hours, first try mostly). **How to apply:** grep the ROM for library version/copyright strings (zlib, libultra, libm, other middleware) and map string xrefs to function starts (n64rom.xref) before hand-transcribing a region; place the original source file per TU, K&R->prototypes is harmless; statics must be written global for n64build ("unnamed piece ... write it global"); a relative #include breaks probe/permuter temp builds -- put headers under src/tgrally/include/tgr/. See [n64-ido-levers-2026-09-27](levers/n64-ido-levers-2026-09-27.md).

LIBULTRA (same session, same method): the ROM's libultra is 0x80260490..end (~205 fns). Source-level exact with per-file flags: gu/* and libc/* at `/* n64-cflags: -O3 */`, os/* and io/* at -O1. Files under src/tgrally/libultra/{gu,libc,os,io}/, types in src/tgrally/include/tgr/ultra.h. This ROM's libultra is an OLD 2.0 revision: osPiReadIo has NO access locking (WAIT_ON_IOBUSY + osRomBase), OSIoMesg has piHandle (set NULL in osPiStartDma), osSpTaskLoad has the OS_TASK_LOADABLE read. sqrtf alone uses `#pragma intrinsic (sqrtf)`; lookat/normalize call sqrtf as a function. Globals a libultra .c defines (timerintr.c's __osCurrentTime etc.) must be DEFINED in that file or IDO emits a separate lui per u64 half. Scratch helper ressym.py reads unresolved extern addresses from the ROM at each relocation -- only trust it on functions whose code already lines up (it added garbage from mismatched ones; addresses outside 0x80000000-0x80800000 are rejected now).
