# Idioms from lane c4fe832e (2026-08-31)

## `if (len != 0) { normalize; return; } zeros` for fcom C3

`fcom [0]; fnstsw ax; test ah,0x40` - C3 set means equal. Orig
`jne zeros` (jump if C3, i.e. len==0) so normalize is fall-through.
`if (len == 0) { zeros; return; } normalize` emits `je normalize`
with zeros as fall-through. Distinguisher: `75 xx` (jne zeros) vs
`74 xx` (je normalize) at the firstdiv. Invert the test. Proven
0x10034420 BrVec3Direction (168 B, MATCH /O2).

## Span point test is 2-arg, y-then-x, no volume pointer

Orig `fld [esp+8]` at entry is y (x at +4). ftol(y), push eax, ftol(x),
Contains(ix, iy). A `int iy = ftol(y); int ix = ftol(x); Contains(ix,iy)`
spills iy to esi (+4 B, push esi). Nested
`Contains(ftol(x*k), ftol(y*k))` is right-to-left y-first with the
first eax pushed. Proven 0x10033FD0 BrSpanTestPoint (55 B, MATCH /O2).

## PfxReset is no-arg DAT_ walk plus a car-table zero

`mov ecx,1; mov eax, offset rec[1].iNext` then
`lea edx,[ecx+1]; inc ecx; mov [eax],dx; add eax,0x20; cmp eax,end; jl`.
End is an exclusive absolute (`0x10ac2c64`), not `base+0x1FE0` as an
addend (`cmp eax,0x1FE0`). After the loop: xor edx,edx; rec[255].iNext=0;
iFree=1; if nCars>0 walk DAT_10af2264 stride 0x2B68 storing 0; then
the three list heads = dx. Distinguisher: `cmp eax,imm32-end` vs
`cmp eax,0x1fe0`; `mov ecx,1` before `mov eax,base`. Proven
0x10033B50 BrPfxReset (92 B, MATCH /O2).
