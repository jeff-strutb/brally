# n64/src/ - the Top Gear Rally decomp

Generated by `n64/tools/n64index.py`; do not edit.

The N64 game's own C, transcribed from the ROM and matched under IDO 5.3.
It shares names and layout with the PC decomp (`src/core/`) so the two read
the same, but it is its own source: the 1997 and 1999 code differ, and
nothing here includes a PC header or is included by the PC build.

One folder per area; a file per responsibility.  Every function carries a
`WHAT IT DOES:` comment and an `@implements 0x80XXXXXX tgr Name` tag.

| area | what it is |
|---|---|
| [`audio/`](audio/README.md) | sound effects, the music player and the audio driver |
| [`controls/`](controls/README.md) | controllers, the Rumble Pak |
| [`drawing/`](drawing/README.md) | frames, display-list helpers, text, fades, per-frame pools |
| [`driving/`](driving/README.md) | car physics, collision, tyres, the computer drivers |
| [`gamedata/`](gamedata/README.md) | ROM loading, memory pools, saves, random numbers |
| [`geometry/`](geometry/README.md) | vector and matrix maths |
| [`menus/`](menus/README.md) | the front-end screens |
| [`racing/`](racing/README.md) | race state, the race display, car artwork, the camera |
| [`startup/`](startup/README.md) | boot, the main loop's game modes, fatal errors |

Tagged functions: T2 48, T4 340.
