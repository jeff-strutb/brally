# Idioms from lane 311669ab (2026-08-31)

## Dot-product addend order is the first fmul, not the comment's "summation"

`fld m10; fld m11; fmul dy` means the first multiply is `m[1][1]*d.y`.
`m[1][0]*dx + m[1][1]*dy + m[1][2]*dz` loads m11 first then fmul dx.
Distinguisher: `d94610 d94614 d84c2414` vs `d94614 d94610 d84c2410`.
Proven 0x10060C30 BrSndPan (380 B, MATCH /O2).

## qsort float comparator: re-deref, no float locals

Orig `fld [ecx]; fcomp [edx]` twice. `const float a = *pA` loads both onto
the x87 stack (`fld st; fcomp st`). Distinguisher: `fcomp dword [edx]` vs
`fld st; fcomp st; fstp`. Spell `*(const float *)pA > *(const float *)pB`.
Proven 0x1005F690 BrRankCmpKey (43 B, MATCH /O2).

## Four same-shape pointer calls unroll; a `for i in 0..3` loop does not

`BR_CAR_SUBPTR(pCar, i)` in a loop is 61 B. Orig is four
`mov eax,[esi+0x168/16c/170/174]; lea r,[eax+0x78]; add eax,0xbc; call`.
Unrolling matches. Proven 0x1005AC60 BrCarBuildMatrices (119 B, MATCH /O2).

## TextListSetBlob is thiscall `ret 0xc`; blob offsets are header-locked

pSrc, size, index)` size-matches 110/110 REGNORM 0. Residue is field

for blob.p) -- BrTextList layout, include/ serialised. Do not edit.
