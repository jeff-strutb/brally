# Idioms from lane 3cf72100 (2026-08-31)

## Global end-pointer, not `*ppEnd`

`br_tex3d_end` orig (19 B): `mov eax,[0x106B7A9C]; test eax,eax; jne; mov eax,[esp+4]; mov [g],eax; ret`.
One stack arg, absolute dword. `if (*ppEnd == NULL) *ppEnd = p` is
`cmp dword [R],0` / `mov [R],R`. Distinguisher: `mov R,[I]; test R,R; mov [I],R`
vs `mov R,[esp+S]; cmp dword [R],I; mov [R],R`.

## Unsigned detail-level ladder is inverted fall-through

`jbe` to level 2, `jbe` to level 1, then `cmp/sbb/neg`. Source is
`if (texmem > thresh) { if (sysmem > 32MB) { sbb/neg; return; } level=1; return; } level=2;`.
`if (texmem <= thresh) level=2; else if ...` emits `ja` and inverts the
ladder. Distinguisher: `3bc1 76 xx` vs `3bc1 77 xx`.

## Glide ChooseLevel stores ONLY the level

D3D writes extra 0x100/0x40/0x20 into four globals (154 B). Glide is 64 B
and one store to 0x100B8498. Distinguisher: 12 extra `mov dword [I],R`.

## grTex max/min are `__stdcall`

Orig: `push esi; call max; push esi; mov edi,eax; call min; sub edi,eax`
with no `add esp,4` between. Cdecl inserts `add esp,4` and can invert
`sub edi,eax` to `sub eax,edi`. Distinguisher: extra `add esp,4` and
`2b c7` vs `2b f8`.

## Integrate-velocity is the six madds, not an adapter CALL

0x1006D600 loads body +0xFC..+0x110, fmul dt, fadd state +0x0C..+0x30.
A memcpy-into-BrRbBody + `BrRbIntegrateVelocity` CALL is 142 B vs 169 B
and drops the x87 stack. Distinguisher: missing 6x `fld [eax+disp]`
before the fmul chain; extra `call`. Remaining residue is fxch schedule
(REGNORM 5+7) -- not source-reachable.

## ViewBuffersRebase 32000-product lea vs add (documented)

96=96 REGNORM 1+1: orig `add ecx, 0x103874A8`, recomp `lea R,[R+I]`.
Already probed in-source. Coalescing, not a missed factor.
