# n64/src/ — architectural areas of the Top Gear Rally build

One folder per area of the engine, matching `src/core/`'s layout so
the two targets browse the same way.

**These folders are mostly empty by design.** The shared engine is one
source, and it lives in `src/core/` — the N64 build compiles that same
source with IDO. Duplicating it here would create a second copy to keep
in sync, which is exactly what the single-source premise avoids. Each
folder's README records what is confirmed in the ROM for that area and
points at the source that produced it.

What *will* be written here is **N64-only platform code** — display-list
building against the RSP, the audio driver, OS glue — which has no PC
twin to share. Of `.text`, 95.55% is still unidentified and that is
where most of it lives.

Generated by `n64/tools/manifest.py`. See `../docs/modules.md`.
