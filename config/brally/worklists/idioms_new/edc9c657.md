# Idioms from lane edc9c657

## Nested 4x4 int copy, not a 16-iter loop (0x10029E50 BrGuMtxStore)

Construct: `void f(const int src[4][4], int dst[4][4]) { int i,j; for (i=0;i<4;i++) for (j=0;j<4;j++) dst[i][j]=src[i][j]; }`

Bytes: `push ebx/ebp/esi; esi=dst; push edi; edi=src; eax=esi; ebx=4;` outer `ecx=src-dst; edx=4;` inner `ebp=[ecx+eax]; [eax]=ebp; eax+=4; dec edx; jne inner; dec ebx; jne outer`. Integer `mov` not fld/fstp.

Distinguisher: a 16-iter `d[i]=s[i]` on `void*` is 29 B / 12 insns (no inner/outer `dec/jne`). Orig 47 B / 23 insns. `float[4][4]` would be x87. Proven MATCH /O2.

## Two 4-arg texture ctors + chained Adler32, void(void) (0x1006C790 BrFontRegisterPages)

Construct: `DAT_large = FUN_10027fb0(&DAT_1007b618, 0x40, 0x40, 4); s = FUN_10001000(0,0,0); s = FUN_10001000(s, &DAT_1007b618, 0x21C00); DAT_small = FUN_10027fb0(&DAT_1009d218, 0x20, 0x20, 4); FUN_10001000(s, &DAT_1009d218, 0x8700);`

Bytes: five cdecl calls, `add esp,0x10` after the 4-arg ctors, `add esp,0xc` after Adler32, second Adler result kept in esi.

Distinguisher: the port stub (`pFont->ahPage[i]=token`) is 25 B / 4 insns vs orig 105 B / 33 insns. Named `sum` local is `mov esi,eax` between the last two Adler calls. Proven MATCH /O2.

## 1-arg DL walker + 5-arg cdecl helper, integer <<2 folded into shift (0x100219D0 BrDlsTileRectE3)

Construct: `unsigned char *f(unsigned char *p) { unsigned w1=*(unsigned*)(p+4), w0=*(unsigned*)p; FUN_100215c0((w1>>10)&0x3FFC, (w1&0xFFF)<<2, (w0>>10)&0x3FFC, (w0&0xFFF)<<2, (w1>>24)&7); return p+8; }`

Bytes: load w1 first (cdecl right-to-left: tile from w1 is the last arg, evaluated first). `shr r,0xA; and 0x3FFC` is `<<2` folded into the 12-bit field extract. `lea eax,[esi+8]; pop esi; ret`.

Distinguisher: a shared `BrDlsTileRectDecode(w0,w1,fInteger,pOut)` that writes a struct never matches either original (they are two call-and-advance walkers). Port decode is 122 B vs orig 75 B. Proven MATCH /O2.

## Re-deref *p vs cached char: SR of p[1]/p[2] into walking pointers (0x10016980 BrFontMeasure)

Construct: `while (*psz) { ... psz[1] ... psz[2] ... psz++; }` re-derefs `*psz`. Caching `c=*psz` and using `c` in the body lets /O2 emit `lea esi,[p+1]; lea ebx,[p+2]` and increment both.

Bytes with re-deref: single esi, `[esi+1]` / `[esi+2]`, 197 B / 79 insns vs orig 198/79 (REGNORM 4+4: ebx/ebp of total vs table, `add edi,edi` vs `shl edi,1`, `cmp al,0x25` vs `cmp cl,al`).

Distinguisher: cached `c` plus `psz[1]==c` is orig's `cmp cl,al` but costs +18 B of derived-pointer walking. Re-deref CSEs `psz[1]==*psz` inside `*psz=='%'` to `cmp al,0x25`. Cannot have both from C at /O2.
