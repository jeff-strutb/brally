- Frame: declared locals at the top in declaration order (all get homes, even copy-propagated b2/a2), then uopt spill slots first-fit in expression-bit order; an unreferenced slot costs frame only if a deeper one is referenced.
- Expression bits = order of insertion into uopt's expression hash (reading order, local copies substituted; cross-block copy-prop trees get late bits). cfe normalises `A <= B` to GEQ(B, A), so the loop test always numbers a2b*y before b2b*x.
