# Boss Rally: Triage screens and working method

- [calling-convention-screen](calling-convention-screen.md): Screen every diff row for a ret-K mismatch - a wrong calling convention is a whole-function defect that can go straight to byte-exact
- [close-queue-lever](close-queue-lever.md): The efficient count-mover is closing the refine batch's CLOSE(n) output, not grinding named near-misses.
- [corridor-scan-2026-09-15](corridor-scan-2026-09-15.md): 0x1005D060 BrAiScanCorridor (the eight-deep corridor lookahead, br_ai.h rule 8's binding gap) fully reverse-engineered and transcribed to T2 in br_ctlai.c; byte-exact is blocked in the C lane by the recursive-thiscall-with-computed-args wall -- it needs a C++ member rewrite.
- [diagnose-dont-hypothesize](diagnose-dont-hypothesize.md): On an exhaustively-mapped function, probing HYPOTHESISED levers yields ~0; MEASURING the original's own behaviour cracks walls. Same day, same functions: a 6-worker sweep of 6 novel levers returned zero wins, a byte-census broke a 12-session wall in one pass.
- [divergence-class-triage](divergence-class-triage.md): Rank match candidates by KIND of divergence, never by byte-diff count - structural is reachable, register allocation is not.
- [generator-compounding-reality](generator-compounding-reality.md): ROI CORRECTION: --refine generators compound ONLY when a residue class is one genuinely-repeated missing-code shape. The long/short/frame/callconv classes were phantom-split / coloring-polluted / mixed-cause and swept ~0. Verify a class is homogeneous BEFORE minting.
- [inlined-helper-match-class](inlined-helper-match-class.md): The reliably matchable divergence class: the port factored a helper the original hand-inlined. Plus the ++c codegen lever and the walls that are NOT worth attacking.
- [parked-is-not-walled](parked-is-not-walled.md): A parked function with regnorm 0+0 and 2-6 diff bytes is usually SOURCE STATEMENT ORDER, not a register-colouring wall. Two such notes were overturned on 2026-09-03.
- [pool-refresh-method-2026-09-10](pool-refresh-method-2026-09-10.md): How to build an HONEST fresh candidate pool (the de-dup filter), and the 2026-09-10 finding that both intake pools are drained: every reachable small/close row is already parked with a dead-list, and NEW pool now comes only from the C++ thiscall lane, structural T2 big-gap rows, or cracking a compiler-decision class.
- [port-safety-additions-block-matches](port-safety-additions-block-matches.md): The port's defensive additions - bounds guards, bounded string helpers, reordered wrapper signatures, NULL checks - are a large and systematic match-blocking class.
- [read-before-assuming-x87](read-before-assuming-x87.md): READ the asm before classifying a block as 'needs x87emu'. Three blocks labelled x87-dense turned out to be trivial, wasting sessions of avoidance.
- [register-rotation-is-a-symptom](register-rotation-is-a-symptom.md): TRIAGE RULE: a whole-function register rotation is a SYMPTOM of a structural source defect in the body, not a terminal coloring wall. Rank residue by the REGISTER-BLIND multiset gap, never by raw diff count.
- [residue-retriage-2026-08-28](residue-retriage-2026-08-28.md): Only 7% (40/580) of the diff residue is a true coloring wall; 223 are complete transcriptions with a >=70% structural gap. The 'coloring, move on' verdict was applied far beyond the evidence. Rank with tools/fnmatch/triage.py.
- [retranscribe-not-patch](retranscribe-not-patch.md): METHOD RULE from the BrTex3dExpand post-mortem: for a function with multiple Ghidra artifacts, RETRANSCRIBE divergent regions fresh from the original asm instead of patching Ghidra's output artifact-by-artifact. Plus: timebox per function by byte value; never claim 'one lever left'.
- [retriage-results-2026-08-28](retriage-results-2026-08-28.md): The structural re-triage PAID: 2 new byte-exact matches (741->743) plus a missing sweep variant (/O2 /Op) that made float-heavy functions unmatchable. Confirms 'coloring wall' verdicts were mostly port-safety/missing-code misdiagnoses.
- [sibling-asymmetry-screen](sibling-asymmetry-screen.md): The cheapest lever on a long-stalled function: find the ONE sibling spelled differently from its parallel twins, or assigned in a different PLACE. Broke two four-plus-session walls in one session.
- [sibling-byte-diff-screen](sibling-byte-diff-screen.md): Byte-diff the extracted ORIGINALS against each other, grouped by identical size - it finds real cause-families (a 7-member clip-plane family, +5 byte-exact) that no residue-class screen sees.
- [slot-census-screen](slot-census-screen.md): tools/slotcensus.py - list every write and read of each original stack slot. Two payoffs: it catches \"one variable emitting two different values\", and a WRITE/READ COUNT ASYMMETRY locates a shared control-flow join (this broke 0x1000A110's 12-session byte-lane wall)
- [t1-intake-lane-method](t1-intake-lane-method.md): How the T1 intake lane works (smallest drafts first, sbs.py side-by-side, six-probe budget) and where it stands; paste-ready spec is docs/T1-INTAKE-LANE.md in the repo.
- [tag-untagged-functions](tag-untagged-functions.md): Scan for implemented-but-untagged functions. They are free verified coverage -- just add the @implements line.
- [tiny-stub-census](tiny-stub-census.md): The <=16B function bucket is 3 classes, not one; 33 real ones landed in tiny_stubs.c
- [untagged-functions-are-free-matches](untagged-functions-are-free-matches.md): ~259 implemented functions across 78 files carry an address in their comment but no @implements tag, so the scorer cannot see them - some already match.
- [verify-blockers-through-twins](verify-blockers-through-twins.md): Blocker lists go stale. Always check shared.csv d3d twins when verifying if a callee is ported -- glide-address-only checks miss d3d-tagged implementations.
