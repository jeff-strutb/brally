- **Callee-saved register cost = 0.25 x (number of basic blocks in the procedure), clamped to [4, 60]** (uopt.c near L471130; count at 0x1001c904). A loop-invariant constant used once in the loop has totalsave 10 (weight 10); 37 blocks = 9.25 -> hoisted into a new s-reg; 41 blocks = 10.25 -> rematerialised. Calls end blocks; statements do not; labels merge; `if (c) {}` with an empty body adds 2 blocks and emits nothing, but its condition still extends live ranges (pick conditions on values already live).
- **`.align 5` before the epilogue of a forever loop**: the standalone per-file grade (and the gate) only match if the function's offset in the .o equals the ROM's mod 32, so the file must be in ROM function order with every earlier function at ROM length.
- **p2 (unconstrained) colouring is first-fit in web-number order, and web numbers follow FIRST MENTION in the code, dead stores included** (declaration order does not matter). BrModRowRead: `note = 0; fx = 0; param = 0; inst = 0;` at the row top (fx/param zeros dead) gives the ROM's a2/a3/t0/t1, flags t2, byte temp t3.
- **constinreg**: a constant stored directly (istr value, ctx 3) is always a register candidate; arithmetic operands (ctx 1/2) are not when they fit an immediate; zero never. Case-block constants get hoisted (no xjp barrier). Store-to-load forwarding does not cross the switch's jump-table dispatch. Open: the ROM's literal `arpOn = 1` without a hoisted constant.
- Local `unsigned short save` + `extern short` global = a hoisted cvt copy; making the global unsigned short gives one s0 web.
