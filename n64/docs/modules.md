# Top Gear Rally (N64) — architectural map

Generated by `n64/tools/manifest.py`; the per-function record is
`n64/config/functions_tgr.csv`. Do not hand-edit either.

The N64 build has no source tree of its own — it is the PC decomp's
source compiled a second time — so a function's module is inherited
from the PC source file it matched. `confirmed` means exactly that.
`inferred` rows are unlocated functions bracketed on both sides by one
module, which IDO's contiguous per-TU emission makes likely but does
not prove; they are never counted as confirmed.
