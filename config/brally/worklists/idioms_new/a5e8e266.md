# Learnings (lane a5e8e266)

## Re-deref a global index, don't cache it (A1 moffs + [eax*4+disp])

Construct: after a byte value lives in AL (key loaded as int32, `cmp al` /
`add al`), store into `arr[g_index]` and then `g_index++`.

Bytes: `movsx ecx, al; mov eax, [g_index]; mov [eax*4+arr], ecx; inc eax;
cmp eax, N; mov [g_index], eax`.

Distinguisher: a named `i = g_index` local puts the index in ecx
(`8B 0D` 6-byte load, `89 0D` 6-byte store) and sign-extends in place
(`movsx eax, al`) -- 2 extra bytes vs orig's `A1`/`A3` moffs and
`movsx ecx, al` first. Proven 0x10040A40 BrPhaseKeyPush (71 B, MATCH /O2).

This is the "re-deref, don't cache" idiom applied to a scaled-index store
that wants EAX.

## Sequential `x *= k1; x *= k2` keeps two `fmul dword [const]`

Construct: `(float)(n*n) * rate * 0.5f * 0.001f` as
`n=n*n; x=(float)n; x*=rate; x*=0.5f; x*=1e-3f`.

Bytes: `imul; mov [esp+4],edx; fild [esp+4]; fmul [ecx+rate]; fmul [0.5];
fmul [0.001]; ret 4`.

Distinguisher: `return (float)n * rate * 0.5f * 1e-3f` folds the two
literals into one `fmul dword` (32 B vs orig 38 B). Proven 0x10041130
BrUiTweenCurve (38 B, MATCH /O2). thiscall + one stack arg is
`__fastcall(this, int _edx, int n)` / `ret 4`.

## Leave: absolute globals + thiscall f1C / f00, memset inlines to `rep stosd`

Construct: `if (p) { p->vtbl->f1C(p); p = 0; }` over a named global, plus
`memset(g_arr, 0, 4*N)` of a global array.

Bytes: `mov ecx, [g]; xor esi,esi; cmp ecx,esi; je; mov eax,[ecx];
call [eax+0x1c]; mov [g],esi` and `mov ecx,N; xor eax,eax; mov edi,offset g;
rep stosd`.

Distinguisher: `Br31DestroyPhase(&g_pExt->p)` / `memset(g_pExt->arr,0,n)`
go through a context pointer (extra load, CRT memset call). Proven
0x10040570 (132 B) and 0x100406E0 (161 B), MATCH /O2.

Slot +0x00 with `push 1` is `__fastcall f00(this, pVtbl, 1)` -> `call [edx]`.
Orig 0x10040420 uses `call [eax]` for the same slot after an eax/edx
alternation -- REGNORM 0 coloring residue (119 vs 117).
