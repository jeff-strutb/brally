# Idioms from lane 10e0d736 (2026-08-31)

## 0x10031xxx D3D / 0x1002A8xx-0x1002ADxx Glide is an /Od TU

Scratch ring, TexSizeShift, GfxEmitTexCmd, GfxClearScreen, GfxFillRect
match under `/Od` and NOT `/O2`. Distinguisher: orig `push ebp; mov ebp,esp`
with `sub eax,1` / `add eax,1` (not `inc`/`dec`) and `imul r,r,imm`
(not lea-scale). Neighbours in the same D3D 0x10031xxx cluster are the
same class. Camera/lighting just below (LookAt / FromLookAt) is `/O2`.

## do-while(0) emit macro is visible under /Od

`do { p=pGfx; pGfx=p+2; p[0]=w0; p[1]=w1; } while(0)` emits
`xor ecx,ecx; test ecx,ecx; jne body` after the stores under /Od.
Orig has no such tail. Distinguisher: extra xor/test/jne after each
emit. Write the four statements inline for /Od TUs.

## `if (bit) return; emit;` vs `if (bit==0) { emit; }` under /Od

`!= 0` + early return is `test; je emit; jmp end`. Orig is
`test; jne end` with emit as fall-through. Distinguisher: `74 xx eb yy`
vs `75 xx`. Invert to `if (bit == 0) { emit }`.

## Re-read pGfx to bump, don't add the local

`p = pGfx; pGfx = p + 2` CSEs to `mov ecx, [local]; add ecx, 8`.
Orig: `mov eax, [pGfx]; mov [local], eax; mov ecx, [pGfx]; add ecx, 8`.
Distinguisher: second load is `[pGfx]` vs `[ebp-4]`. Spell
`pGfx = pGfx + 2`.

## Recompute `i * stride`, don't cache a rec pointer

Orig BrGfxEmitTexCmd does `imul eax,eax,0x24` twice, then
`[base+i*0x24+0x20]` and `[base+i*0x24]`. A `rec = base + i*stride`
pointer is one imul plus `[rec+disp]`. Distinguisher: two `imul r,r,0x24`
and `[R+R+I]` vs one `lea` and `[R+I]`.

## Scratch ring is four absolute addresses, signed `% 32`, re-read index

`n = n + 1` (mov/add/mov, not inc-dword). `(iScratch+1) % 32` is the
cdq/xor/sub/and signed remainder, then `mov [i],eax; mov eax,[i];
imul eax,eax,0x18; add eax, ring`. A pointer field `g_s17.pScratch`
is a load, not `add eax, imm`. Distinguisher: `push 0x106ed570`
(address of the wait object) vs `push [g.pScratchWait]`.

## TexSizeShift overwrites the size slot, 0x28 sprintf frame, if/else tree

`size = size - 1` stores back to `[ebp+8]`, then every mask re-reads
that slot (`and cl,0` for `~0xFF`). A named `n` keeps a register.
`char buf[0x28]` + IAT sprintf, not snprintf/64. Each arm is a store,
not a ternary. Distinguisher: `sub esp,0x28` and `mov [ebp+8],eax`
vs a local and `sub esp,0x40`.

## Inlined pack is a CALL-sized miss; BrLightDirsFromLookAt inlines six packs

A static `s17_pack_dirs` stays a CALL (recomp 75 B vs orig 186 B).
Six `BrPackNormalByte((double)pM->m[row][col])` assignments inline
to the fld/fstp-qword/call/mov-[edi+8..1a] chain. Distinguisher:
missing 6x `fld dword; fstp qword; call; mov byte [R+I], al`.

## /Od fill/clear: unsigned short colour, one cursor local per emit

`or al,1` (3-arg clear, packed in eax) vs `or ecx,1` (7-arg fill,
packed in ecx) then `mov word [ebp-4], ax/cx`. `(unsigned)c | ((unsigned)c<<16)`
is one `and 0xffff` per operand (dword load of the 2-byte slot);
an extra `& 0xFFFF` doubles the and. Seven named pointer locals
fill a `sub esp,0x20` frame. Distinguisher: `mov word [ebp-4]` plus
ebp-8..ebp-20 cursors vs one reused cursor / helper CALL.

## screenW is pGfx+4 in this TU, not BrS17State.screenW

Glide `0x106e7714` is adjacent to pGfx `0x106e7710`. `g_s17.screenW`
is a later field and emits the wrong displacement. Matching-build
uses `DAT_106e7714` / `DAT_106e9a2c` / `DAT_106ed674`. Distinguisher:
`mov edx, [pGfx+4]; mov ecx, [scale]; shl edx, cl` vs a pointer load
from the struct.
