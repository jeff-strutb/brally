## DirectInput GetDeviceState is stdcall CINTERFACE + a GLOBAL device (0x10070490 MATCH 78 B)

`push buf; push 0x100; push this; call [vtbl+0x24]` (slot 9), no `add esp`.
Acquire is `[vtbl+0x1c]`. Device is `mov eax,[g]` three times (re-deref after
each call), not `g_pBr72Env->pDik`. NULL device returns **1** (`jge` treats
it as success). DIERR_INPUTLOST is `test eax,eax; jge; cmp eax,0x8007001e`.

Shrink-wrap: orig `push esi` is before the NULL test so the `return 1` path
`pop esi`. Assign pState to a local after loading the global, then
`if (pDev==NULL) hr=1; else { use p; } return hr;` so esi is live on both
paths.

Distinguisher: `ff 51 24` / no `83 c4` vs cdecl `e8; 83 c4 0c`. `a1 g` vs
`mov eax,[env]; mov eax,[eax+off]`.

## Jump table 0..4 with unsigned ja, stores through globals (0x1003DA90 MATCH 162 B)

`cmp eax,4; ja default; jmp [eax*4+table]`. Case 4 belongs IN the table;
a prior `if (n>4)` plus `switch` 0-3 splits into `jbe` + `cmp eax,3`.
Default (>4) writes the case-0 pair in reverse order. Stores are
`mov [imm],imm` (BSS globals), not `mov [env+off],imm`.
