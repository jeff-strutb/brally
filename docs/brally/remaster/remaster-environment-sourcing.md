# Remaster environment sourcing

*Recorded 2026-10-01.*

> Remastered track props/foliage sourcing plan (2026-09-30) -- Poly Haven first, Meshy for landmarks, exceptions list; where the files live

DECIDED 2026-09-30 with the project lead: Remastered (~ toggle) = modern high-end models/textures at Forza richness (dense scatter beyond 1:1); Original = untouched N64 pieces. Seamless swap.

- **Poly Haven (CC0) is the default source.** Only assets we know 100% the tracks need; manifest at `ports/common/models/env/manifest.json` (gitignored dir), fetcher `env/fetch.py` (md5-checked, resumable, 4k .blend models + 4k surface maps), files under `env/polyhaven/`. First pull: 95 models + 61 surfaces, ~20 GB.
- **Meshy for landmarks/hero props** (lighthouse, windmill, plane, huts, hotels, mine carts...), curated prompts, same pipeline as cars ([remaster-car-meshy-pipeline](remaster-car-meshy-pipeline.md)): the project lead says Meshy is very good at buildings/vehicles.
- **Exceptions (running list):** `env/EXCEPTIONS.md` -- palms, jungle canopy, vines, hedge/fern walls, signs/billboards (brands need new art), plus track-fitted walls/fences rebuilt from original shapes. "Deal with later."
- Megascans is paid since 2025 and its trees may be Unreal-only -- not used. Low-poly packs (Quaternius/Kenney) fail the Forza bar ([remastered-look](remastered-look.md)).
- **State 2026-09-30 (uncommitted):** tools `ports/brally-wasm/tools/remaster_env_{bake,place,impostor}.py`; runtime `host/host_env.m` + `native/env.m` (@replaces BrGbiDList 0x10021020 = sees every instance list jump in every view; BrObjDlBuild 0x1000CBA0 for its lighting path) + 3-line shadow hook in host_fx.m. Built in a separate git worktree while other work used the main tree. Hard-won facts: foliage = authored LODs only (Collapse breaks leaf-card UVs); alpha-test textures need coverage-preserving, alpha-weighted mips + edge dilation; impostors (8 views, 512px, Cycles not Eevee) beyond 5 radii; mesh LODs to 9r cost 17.8M tris -> now <=1.3M, GPU p90 14.8 vs 15.3 ms env-off on Mountain. Track pick in scripts persists between runs (step 1 click at a time). Mountain 5,126 trees in rows behind strip cards, clear of the racing line (header +0x70 ring), on the drawn ground.
- **2026-10-01 method (PROJECT: stop launching like a human; verify offline):** pick a track deterministically with BR_SAVEDIR=<fresh dir> + the cheat prefix of tools/brally/brbox_scripts/34 + k TRACK clicks (k: 0 coast,1 mountain,2 bonus,3 amazon,4 desert,6 mine; race = no cheats, k=1). Scripted runs never touch the player's save (host_app.m uses build/brally/wasm32/save). Command-line chosenTrack= is overridden by the menu. BR_TRKDUMP=dir dumps the loaded track image (palettes filled) -> captures in session scratch trkdump/; palette (CI) textures cannot be catalogue-hashed (upload differs) -> tag by eye from true-colour sheets. Packaging: package_app.sh copies env data to Resources/env (the app showed NO env until 2026-10-01). Scatter kinds from texmat.csv via offline FNV of RGBA16 uploads (70-80% hit).
