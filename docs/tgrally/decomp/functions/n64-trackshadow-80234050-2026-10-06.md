**Levers that generalise (IDO 5.3):**
- `n = c & K` where n's value is used again in the block -> uopt makes a CSE temp (coloured, often v1) and ugen writes the and there: no t-ring pop. `c &= K; n = c;` -> ugen dest-scratch (ring pop) and as1 renames to `andi n, c; move c, n`. A one-slot t-ring shift with identical code = look for this.
- uopt copy-propagates `n = c` forward until c is redefined; a later redefinition of c (even one that dies, `*dl++ = c = vtx`) stops it, else c stays live across calls and goes to an s-reg.
- Reusing a short-lived variable in a hot loop (c as tc[0]) raises its save so it wins v0 over local temps.
- nocs = ((occ + live blocks - 2) >> 2) + 2: `do { ... } while (0)` adds empty blocks in a region, lengthening the webs live there (fl 620 -> 516) without code.
- `cc -S` on a full TU gives ugen's pre-as1 asm (register choices before as1 renaming): the fastest way to see scratch pops and CSE temps. Scratch tools: f40b7a scratch ts/ (g.py, uc.py ucode, S.sh, cdxd.py).
