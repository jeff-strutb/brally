## stdcall glyph blit, short iGlyph, y-then-x __ftol (0x100545C0 MATCH 59 B)

`int __stdcall f(short iGlyph, float x, float y, int unused)` with `ret 0x10`
and `return 1`. Orig: `movsx ecx, word [esp+4]`; `fld [esp+0xc]` (y) before
any integer work; `mov eax, [sheet5.fBlit]`; `shl ecx,4; add ecx, rectB`;
push flags, rect, `push 5`; call __ftol (y); `fld [esp+0x14]` (x); call
__ftol; push; cdecl blit; `add esp,0x14`.

Distinguisher: `0f bf 4c 24 04` + `c2 10 00` vs cdecl `ret` / int iGlyph
(`mov eax,[esp+4]`).

## thiscall + 4 stack args: struct extras so edx is free (0x10054550, 113 vs 112)

`__fastcall(this, int dummy, short, float, float, int)` occupies edx; after
`mov al,[ecx+8]` this is dead so sheet lands in ecx, and the rect add is
`81 c1 imm32` (6 B) not `05 imm32` (5 B, add eax). Struct-typed extras
(`typedef struct { short v; }`) keep edx free like true thiscall, but VC5
still picks ecx for sheet once this dies. Orig: `xor edx,edx` then `mov edx,2/3/4/0x34`; `movsx eax,dx`; `lea eax,[eax+eax*2]`; `mov ecx,[eax*8+fBlit]`; `movsx eax,word [esp+4]`.

Distinguisher: `33 d2` / `ba 02 00 00 00` / `05 xx xx xx xx` vs `33 c9` /
`b9 02 00 00 00` / `81 c1 xx xx xx xx`.

## Pointer-walk cursor/limit must be distinct symbols (0x10058540)

Four inlined loops: ecx starts at base+4, `add ecx,16` at the top, stores at
`[ecx-0x14/-0x10/-0xc/-8]`, signed `jl` against a literal end address.
Same-array `&A[0][1]` / `&A[n][1]` CSE to BSS-relative immediates
(`mov ecx,4` / `cmp ecx,0x444`, no reloc). Distinct `extern char DAT_10ac420c[]`
/ `DAT_10ac464c[]` emit `mov ecx, offset` / `cmp ecx, offset` relocs.

A is signed /8 %8 (bias-and-mask); B/C magic /5 with ebx=cols; D magic /3
and `i+15 < 24`. Compute **div first** so esi holds top while `idiv ebx`
needs cols in ebx (mod-first puts cols in esi and drops `push ebx`).

Residue (REGNORM 0, 309=309): `inc i` / `cmp p,limit` schedule into the last
two stores when the condition does not use i. `volatile int *p` keeps the
four stores together except that hoist. `volatile int i` reloads i and
blows the size (+70 B).

## Re-deref the count after realloc (0x10027A10, REGNORM 0, 83 vs 85)

Append is grow+inc only (no record copy). `if (count >= max)` unsigned `jb`;
`max += 0x100`; `BrChkRealloc(p, max*0x2B4, "AppendTexture: atdb")` (string
pushed first). Then `mov eax,[count]; inc; mov [count],eax; dec` - cache
the old count and you get `lea edx,[esi+1]; mov eax,esi` (no inc/dec).

Residue: max in eax (`a1` + `add eax,0x100` = `05`, 5 B) vs orig max in ecx
(`8b 0d` + `81 c1 00 01 00 00`, 6 B). Short-form add-eax steals the register.
Nmax local does not survive CSE.
