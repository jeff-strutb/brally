# Lane a461c817 - proven this session

## Variable memcpy is `rep movsd` / `rep movsb`, not a CRT call

Construct: `memcpy(pDst, pBase + off, cb)` with `cb` a runtime length, dest in
edi and src in esi.

Bytes: `mov edx,ecx; shr ecx,2; rep movsd; mov ecx,edx; and ecx,3; rep movsb`.

Distinguisher: orig that sequence vs `push; call memcpy; add esp,0xc`
(BrTexCopyRecords 0x10031AC0, 188 B, MATCH /O2).

## Raw dword loads, not BrPtrAt / BrRd32 helpers

After fixup the record slots ARE host pointers. `mov edi,[eax-8]` /
`mov ecx,[eax+0x18]` / `cmp word [edx+2],2`. BrPtrAt (resolve+NULL) and
BrRd32 (memcpy of 4) each emit a `call`.

Distinguisher: orig 0 helper calls vs recomp 9 (BrTexCopyRecords).

## Loop-invariant `ebx = -8 - table` for a parallel array

Construct:
```
adj = -8; pWalk = table + 8; adj -= (int32_t)table;
pFlags = (char *)g_pTexFlags; pFlags += adj;
uSel = *(uint32_t *)(pFlags + (int32_t)pWalk + 0x20);
```

Bytes: `mov ebx,-8; lea eax,[ecx+8]; sub ebx,ecx;` then in the body
`mov ecx,[g_pTexFlags]; add ecx,ebx; mov ecx,[ecx+eax+0x20]`. ebx is NOT
incremented with the walk.

Distinguisher: combining adj+pWalk into a walking ebx adds `add ebx,0x24`
and steals ebp for a 0x18 CSE (orig 188 vs that form 210).

## `?:` of two constants is sub / neg / sbb, not a branch

`(uSel == 0x01000000) ? 0x20 : 0x200` after `and ecx,0x0F000000` is
`sub ecx,0x01000000; neg ecx; sbb ecx,ecx; and ecx,0x1e0; add ecx,0x20`.

## `~b & a` wants the and dest on the ~b register

`not esi; and esi,eax` leaves a in eax for a later `and eax,edx`.
`mov edi,eax; and edi,esi` is the extra callee-saved (BrBitEdgeSplit
0x1002F660, REGNORM 3+0). `t = ~b; t &= a; a &= b;` did not flip the dest.
Allocator residue on this size.
