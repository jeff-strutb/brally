# 0x1003CF50 BrOpt3A00 - duplicated unlock on the too-few arm

Construct: `dwCurrentPlayers <= 1` copies BrStrGet(0xBB), calls BrSub1003D210,
strcpy from g_aBr39B720, then **Unlock/Free/return 1 right there**. The
players>1 arms share a later Unlock/Free tail. Folding too-few into that tail
drops 38 B (dedicated IAT pair + ret).

Also:
- KERNEL32 is IAT (`mov esi,[__imp_GlobalHandle]; call esi` then
  `call [__imp_GlobalUnlock]`), not BrGlobal* wrappers (`call; add esp,4`).
- SetSessionDesc is stdcall `push 0; push desc; push this; call [vtbl+0x7c]`.
- strcpy of BrStrGet is `repne scasb` + `rep movsd/movsb`, not a CRT call.
- Slot walk is `cmp p, &table[8]; jl` (signed).

Distinguisher: orig 491 B with a too-few-local Handle/Unlock/Free/ret vs a
shared tail that `jmp`s there from too-few (453 B, 4 regions).

Proven MATCH /O2, 491 B.
